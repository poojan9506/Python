# Python Projects

A collection of beginner-to-intermediate **Python** projects, each kept in its own folder. The projects focus on core fundamentals: functions, classes, file handling, JSON storage, input validation and exception handling.

## Projects

| # | Project | Description | Key Concepts |
|---|---------|-------------|--------------|
| 1 | [File & Folder Management System](./File%20%26%20Folder%20Management%20System) | Command-line tool to create, read, update and delete files and folders | `pathlib`, `shutil`, file handling, exception handling |
| 2 | [Library Management System](./Library%20Management%20System) | Command-line system to manage books and members, and track borrowing and returns | OOP (classes), JSON storage, unique ID generation, input validation |

### 1. File & Folder Management System
A menu-driven program that performs full CRUD operations on files and folders: create, list, rename, append or overwrite content, and delete.

### 2. Library Management System
A menu-driven program where a librarian can add books, register members, and borrow or return books. Data is saved in a `library.json` file, so records stay even after the program closes.

## How to Run Any Project

1. Make sure Python 3 is installed:
   ```bash
   python --version
   ```
2. Clone the repository:
   ```bash
   git clone https://github.com/poojan9506/Python.git
   ```
3. Open the project folder you want and run it:
   ```bash
   cd "Python/Library Management System"
   python main.py
   ```

All projects use only the Python standard library, so nothing extra needs to be installed.
